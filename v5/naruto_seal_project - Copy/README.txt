# Naruto hand-seal recognition (Pattern Recognition microproject)

Two-hand MediaPipe landmarks -> classical ML (KNN / Logistic Regression / Naive Bayes)
plus a small neural network as an extra comparison -> live seal recognition ->
seal *sequences* -> jutsu animations.

## Setup
```
pip install -r requirements.txt
```
(`mediapipe==0.10.14` is pinned on purpose: newer releases removed `mp.solutions`.)

## Run order
| Step | Command | What it does |
|---|---|---|
| 1 | `python clean_dataset.py` | One-time: removes zero-padded single-hand rows + the fake `wrist_distance` column from your old CSV, writes `hand_seal_dataset_clean.csv`, tells you which seals are too small |
| 2 | `python collect_data.py --seal Tiger` | Re-collect any seal that was dropped/weak (both hands must be visible; 9 conditions x 25 frames; 5 s prep). Repeat per seal. Also collect `Normal/Neutral` (hands relaxed) |
| 3 | `python train_compare.py` | Grouped cross-validation of all 4 models, confusion matrices, per-seal recall, saves `model.pkl`. Use `--model KNN` to force which model the live app uses |
| 4 | edit `jutsu_config.json` | Pick control seals + your jutsu sequences from seals that scored well in `per_seal_recall.csv` |
| 5 | put pictures in `seal_images/` | `Ram.png`, `Boar.jpg`, `Special Cross Seal.png` ... (crop them from `hand seals.jpg`) |
| 6 | `python jutsu_app.py` | The live app |

Tests (no webcam needed): `python test_sequence_engine.py` and `python test_app_headless.py`.

## How the live app works
* **Both hands** = a seal. Hold ~0.7 s and it registers once. Same seal twice in a row: relax in between.
* **Control seals** (config): START begins recording, UNDO removes the last seal, CAST matches the
  sequence and plays the jutsu. Control seals can't appear inside jutsu sequences.
* **One hand** = pointer. Hold your index fingertip in SELECT JUTSU for 7 s to open/close the list.
* Animations: procedural OpenCV effects by default. Drop a black-background clip named after the
  jutsu (e.g. `effects/fireball_jutsu.mp4`) and it is blended over the camera image instead.
* Keys: J list, C clear, H hints, Q quit. `--cam-w 1120 --cam-h 630` makes the picture bigger.
